# TahaDev WordPress Project

## Complete Local WordPress Development Setup

This project demonstrates a complete local WordPress development environment created using XAMPP.

## Project Features

• Custom WordPress database configuration
• Astra theme
• Taha Astra Child Theme
• Five essential WordPress plugins
• Five custom action hooks
• Three custom filter hooks
• Custom user role with defined capabilities

## Essential Plugins

1. Elementor
2. WooCommerce
3. Contact Form 7
4. Yoast SEO
5. UpdraftPlus

## Custom Hooks

### Action Hooks

• wp_enqueue_scripts
• wp_footer
• wp_body_open
• admin_notices
• init

### Filter Hooks

• the_title
• the_excerpt
• the_content

## Custom User Role

Taha Content Manager was created with permissions to read, edit, publish and delete posts, and upload media files.

## Development Environment

XAMPP was used to run Apache and MySQL locally. WordPress was installed in a custom local project folder and connected to a custom MySQL database.
